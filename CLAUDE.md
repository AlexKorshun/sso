# SSO — gRPC-сервис авторизации

Учебный проект по гайду «Пишем gRPC сервис на Go — Сервис авторизации»
(Тузов // Golang, YouTube). Сервис аутентификации/авторизации (SSO) на Go
с gRPC-интерфейсом.

## Что строим

gRPC-сервис с основными RPC:
- `Register(email, password)` — регистрация; пароль хранится как bcrypt-хеш
- `Login(email, password, appID)` — вход, возвращает JWT-токен
- `IsAdmin(userID)` — проверка прав администратора

## Планируемый стек (по гайду — уточняется по ходу)

- **gRPC + Protocol Buffers** — транспорт и контракт; кодогенерация через
  `protoc` (`protoc-gen-go`, `protoc-gen-go-grpc`). Proto-контракты часто
  выносят в отдельный модуль/репозиторий.
- **SQLite** — хранилище
- **golang-migrate** — миграции схемы
- **JWT** (`golang-jwt`) — токены; **bcrypt** — хеширование паролей
- **cleanenv** — конфигурация из YAML + переменных окружения
- **slog** — структурированное логирование
- **Taskfile** (Task) — раннер команд (в гайде вместо Make)

## Архитектура (ориентир, детали по ходу гайда)

Слоёная, зависимости направлены внутрь через интерфейсы:

```
gRPC-хендлер  →  сервис (Auth)  →  storage (SQLite)
```

- транспортный слой (gRPC) не знает о БД
- бизнес-логика — в сервисе `Auth`
- storage за интерфейсом, чтобы реализацию можно было подменить

Точную раскладку по пакетам (`cmd/sso`, `internal/...`) заранее не фиксируем —
устаканится по мере прохождения гайда.
